# vedit — Scorciatoie da tastiera

Tutte le scorciatoie saranno personalizzabili, con i preset "stile CapCut" e "stile Premiere" (Fase 8).

## Disponibili (Fase 0: finestra di riproduzione)
| Tasto | Azione |
|---|---|
| Ctrl+O | Apri un video |
| Spazio | Riproduci / pausa |
| ← / → | Fotogramma precedente / successivo |
| Home / Fine | Vai all'inizio / alla fine |

## Previste (dalla specifica, a partire dalla Fase 1)
| Tasto | Azione |
|---|---|
| S | Dividi al playhead |
| Canc | Elimina (con ripple sulla traccia principale) |
| Q / W | Taglia a sinistra / a destra del playhead |
| J / K / L | Indietro / pausa / avanti (pressioni ripetute = più veloce) |
| Ctrl+Z / Ctrl+Maiusc+Z | Annulla / ripeti |
| Ctrl+K | Ricerca universale |
| Ctrl+rotella | Zoom della timeline |
| 1–9 | Cambio inquadratura in multicamera |
