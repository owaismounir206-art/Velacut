# velacut — Scorciatoie da tastiera

Le stesse sono nell'app: Menu → **Scorciatoie da tastiera**. I tasti singoli funzionano quando non si sta scrivendo in
un campo di testo. Tutte le azioni si trovano anche con la ricerca universale (`Ctrl+K`) e nel menu del tasto destro.

## Riproduzione

| Scorciatoia | Azione |
|---|---|
| `Spazio` | Riproduci / pausa |
| `J` `K` `L` | Indietro, pausa, avanti (premendo di nuovo: più veloce, fino a 8×) |
| `←` `→` | Fotogramma precedente / successivo |
| `Maiusc+←` `Maiusc+→` | 10 fotogrammi indietro / avanti |
| `↑` `↓` | Taglio precedente / successivo |
| `Home` `Fine` | Vai all'inizio / alla fine |
| `F11` | Anteprima a schermo intero (`Esc` per uscire) |

## Montaggio

| Scorciatoia | Azione |
|---|---|
| `S` o `Ctrl+B` | Dividi alla testina |
| `Q` `W` | Elimina a sinistra / a destra della testina (lo spazio si chiude) |
| `[` `]` | Accorcia l'inizio / la fine della clip selezionata alla testina |
| `Canc` o `Backspace` | Elimina la selezione |
| `Maiusc+Canc` | Elimina e chiudi lo spazio |
| `Ctrl+D` | Duplica |
| `Ctrl+A` | Seleziona tutto (tracce non bloccate) |
| `Esc` | Deseleziona |
| `Ctrl+Alt+C` `Ctrl+Alt+V` | Copia / incolla attributi (effetti, filtri, regolazioni, animazioni) |
| `Ctrl+T` | Aggiungi un testo |
| `Ctrl+Z` | Annulla |
| `Ctrl+Maiusc+Z` o `Ctrl+Y` | Ripeti |
| `1` … `9` | Cambia inquadratura (clip multicamera) |

## Timeline

| Scorciatoia | Azione |
|---|---|
| `M` | Aggiungi un marcatore alla testina |
| `I` `O` | Imposta il punto di entrata / uscita |
| `Alt+X` | Cancella entrata e uscita |
| `N` | Traccia principale magnetica sì / no |
| `\` | Aggancio sì / no |
| `+` o `=` / `-` | Ingrandisci / riduci (anche `Ctrl`+rotella) |
| `Ctrl+0` | Mostra tutto il video |
| `Ctrl+1` | Zoom predefinito |
| rotella / `Maiusc`+rotella | Scorri nel tempo / tra le tracce |
| `Alt` trascinando un media su una clip | Sostituisci la clip mantenendo durata ed effetti |

## Progetto

| Scorciatoia | Azione |
|---|---|
| `Ctrl+N` | Nuovo progetto |
| `Ctrl+I` | Importa media |
| `Ctrl+E` | Esporta |
| `Ctrl+Maiusc+E` | Salva il fotogramma corrente come immagine |
| `Ctrl+K` | Ricerca universale (comandi, effetti, transizioni, filtri, testi, musica, media) |
| `Ctrl+,` | Preferenze |

Non c'è "Salva": ogni modifica viene salvata da sola entro circa 2 secondi.
